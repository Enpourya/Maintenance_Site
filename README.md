## 🖼️ پیش‌نمایش

صفحه اصلی یک صفحه "در حال بروزرسانی" با طراحی مدرن و شیشه‌ای (Glassmorphism) است که شامل:

- **پس‌زمینه گرادیانت متحرک** با ۵ رنگ هماهنگ
- **لوگوی سایت** با افکت‌های درخشان
- **نام سایت و متن در حال بروزرسانی** با انیمیشن‌های جذاب
- **آیکون‌های شبکه‌های اجتماعی** با حالت شیشه‌ای
- **افکت‌های هاور و کلیک** تعاملی
- **طراحی کاملاً واکنش‌گرا** برای موبایل و تبلت

## 🔧 نیازمندی‌ها

- حداقل نیازمندی‌های سرور:

## ⚙️ تنظیمات پیشرفته

تغییر رنگ‌های پس‌زمینه
در فایل styles.css خط زیر را پیدا کنید:

```
css
body {
    background: linear-gradient(135deg, #800080, #4B0082, #6A5ACD, #D8BFD8, #C0C0C0);
}
```
رنگ‌ها را به دلخواه تغییر دهید:

```
css

/* مثال: رنگ‌های سبز */
background: linear-gradient(135deg, #11998e, #38ef7d, #56ab2f, #a8e063, #dce35b);
```
# تغییر فونت

- در فایل index.html و styles.css، فونت پیش‌فرض Vazirmatn استفاده شده است. برای تغییر:

```
css
body {
    font-family: 'YourFont', 'Vazirmatn', Tahoma, sans-serif;
}
تنظیمات CSP (Content Security Policy)
در فایل index.html:

html
<meta http-equiv="Content-Security-Policy" 
      content="default-src 'self'; 
               img-src 'self' data: https:; 
               style-src 'self' 'unsafe-inline'; 
               script-src 'self' 'unsafe-inline'; 
               connect-src 'self' https:;">
تنظیمات Cache
برای غیرفعال کردن کش در صفحه اصلی:

html
<meta http-equiv="Cache-Control" content="no-cache, no-store, must-revalidate">
<meta http-equiv="Pragma" content="no-cache">
<meta http-equiv="Expires" content="0">
```

در فایل admin-e/.htaccess اضافه کنید:
```
apache
 محدود کردن دسترسی به پنل مدیریت

    Order Deny,Allow
    Deny from all
    Allow from 192.168.1.100  # IP خود را وارد کنید
    Allow from 127.0.0.1      # لوکال هاست
</FilesMatch>
```

# 🔍 عیب‌یابی

- مشکلات رایج و راه‌حل‌ها
❌ خطای 403 در پنل مدیریت
- دلیل: مجوز دسترسی نادرست
- راه‌حل:

```
bash
chmod 755 admin-e/
chmod 644 admin-e/*.php
chmod 666 admin-e/data.json
```

❌ لوگو نمایش داده نمی‌شود
- دلیل: مسیر اشتباه یا عدم وجود فایل
- راه‌حل: مسیر لوگو را بررسی کنید. باید نسبت به پوشه اصلی باشد:

```
php
# صحیح:
icon/logo.png
# نادرست:
/admin-e/icon/logo.png
../icon/logo.png
```

❌ تغییرات ذخیره نمی‌شود
- دلیل: عدم دسترسی نوشتن روی data.json
- راه‌حل:

```
bash
chmod 666 admin-e/data.json
# یا
chmod 777 admin-e/data.json
```

❌ خطای CORS در کنسول
- دلیل: تنظیمات CORS در سرور
- راه‌حل: در فایل .htaccess اصلی:
```
apache
Header set Access-Control-Allow-Origin "*"
```

❌ آپلود فایل کار نمی‌کند
- دلیل: محدودیت حجم یا نوع فایل
- راه‌حل: در config.php:

```
php
$maxSize = 10 * 1024 * 1024; // افزایش به 10MB
$allowedTypes = ['image/jpeg', 'image/png', 'image/gif', 'image/webp'];
```

❌ صفحه مدیریت سفید است
- دلیل: خطای PHP یا نشست (Session)
- راه‌حل: فعال کردن نمایش خطاها (موقت):

```
php
// در ابتدای config.php اضافه کنید
ini_set('display_errors', 1);
error_reporting(E_ALL);
```

# بررسی سلامت سیستم
یک فایل health-check.php در پوشه admin-e ایجاد کنید:

```
php
<?php
echo "<h1>🔍 بررسی سلامت سیستم</h1>";

// بررسی نسخه PHP
echo "<p>نسخه PHP: " . phpversion() . "</p>";

// بررسی اکستنشن‌ها
$extensions = ['json', 'fileinfo', 'session', 'mbstring'];
foreach ($extensions as $ext) {
    echo "<p>" . (extension_loaded($ext) ? "✅" : "❌") . " $ext</p>";
}

// بررسی مجوزها
echo "<p>data.json: " . (is_writable('data.json') ? "✅ قابل نوشتن" : "❌ غیرقابل نوشتن") . "</p>";
echo "<p>icon/: " . (is_writable('../icon/') ? "✅ قابل نوشتن" : "❌ غیرقابل نوشتن") . "</p>";

// بررسی فایل data.json
if (file_exists('data.json')) {
    $data = json_decode(file_get_contents('data.json'), true);
    echo "<p>data.json: " . ($data ? "✅ معتبر" : "❌ نامعتبر") . "</p>";
} else {
    echo "<p>data.json: ❌ وجود ندارد</p>";
}
?>
```
